# RDPAudit 2.0 - Community संस्करण

<!-- md-i18n:switcher -->
**अन्य भाषाओं में:** [English](README-EDITION.md) · [Deutsch](README-EDITION.de.md) · [中文](README-EDITION.zh.md) · हिन्दी · [Español](README-EDITION.es.md) · [Русский](README-EDITION.ru.md)

मुफ़्त संस्करण: एक Windows सर्वर, स्थानीय पहचान और स्थानीय प्रतिक्रिया, कोई फ़्लीट नहीं और कोई
एकीकरण नहीं। यह वह संस्करण है जिसे अपने आप में उपयोगी बने रहना चाहिए - सेवा, Configurator और
Windows Firewall में एक ब्लॉक वाला एक अकेला होस्ट ही एक पूर्ण उत्पाद है।

शामिल
-----
* इवेंट संग्रह: Security/RCM/LSM चैनल, हाइब्रिड ETW अंतर्ग्रहण, रिंग बफ़र, WAL स्टोर।
* 21 अलर्ट नियम, RDP गतिविधि के आंकड़े, सत्र मानचित्र, दूरस्थ RDP क्लाइंट दृश्य।
* श्वेतसूची, CIDR रेंज, ब्रेक-ग्लास श्वेतसूची और TTL के साथ Windows Firewall का प्रवर्तन।
* एक MikroTik RouterOS v7 राउटर: ब्लॉक नियम और केवल-पढ़ने योग्य सुरक्षा ऑडिट (S-00..S-35)।
* WinForms Configurator (22 टैब) और ट्रे सूचनाकर्ता।
* शार्डिंग, प्रतिधारण और बैकअप/पुनर्स्थापना के साथ स्थानीय SQLite/WAL डेटाबेस।

शामिल नहीं (Pro में उपलब्ध)
---------------------------
* प्रतिक्रिया ड्राई-रन (`Firewall.ResponseDryRun`)।
* केवल-पढ़ने योग्य HTTPS REST API (`Api.Enabled`)।
* SIEM निर्यात (CEF / LEEF 2.0 / NDJSON)।
* Zabbix पुश चैनल और उसके प्रोविज़निंग कमांड।
* क्रॉस-होस्ट सहसंबंध।

इनमें से कोई भी सुविधा यहाँ कॉन्फ़िगर की जाए, तो सेवा सामान्य रूप से शुरू होती है, प्रत्येक
क्षमता के लिए एक स्पष्ट चेतावनी लिखती है जिसमें वह संस्करण बताया जाता है जिसमें वह काम करेगी,
और उसके लिए कुछ नहीं करती। यह शुरू होने से कभी इनकार नहीं करती: लाइसेंस बेमेल होने के कारण
स्थानीय पहचान खोना बेमेल से भी बुरा होगा।

बिल्ड और सत्यापन
-----------------
    dotnet build RdpAudit.sln -c Release -p:Platform=x64
    dotnet test  RdpAudit.sln -c Release --no-build -p:Platform=x64

विंडो का शीर्षक "- Community" पर समाप्त होता है, और `GetEditionInfo` (IPC 102) बताता है कि इस
बाइनरी में कौन-सी क्षमताएँ हैं।
