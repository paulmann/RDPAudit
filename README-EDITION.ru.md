# RDPAudit 2.0 — издание Community

<!-- md-i18n:switcher -->
**На других языках:** [English](README-EDITION.md) · [Deutsch](README-EDITION.de.md) · [中文](README-EDITION.zh.md) · [हिन्दी](README-EDITION.hi.md) · [Español](README-EDITION.es.md) · Русский

Бесплатное издание: один сервер Windows, локальная детекция и локальный ответ, без парка машин
и без интеграций. Это издание должно оставаться полезным само по себе: один хост со службой,
Configurator и блокировкой в брандмауэре Windows — уже законченный продукт.

Входит в издание
----------------
* Сбор событий: каналы Security/RCM/LSM, гибридный приём через ETW, кольцевой буфер, хранилище WAL.
* 21 правило тревог, статистика активности RDP, карта сеансов, просмотр удалённых клиентов RDP.
* Применение правил брандмауэра Windows с белым списком, диапазонами CIDR, аварийным белым списком и TTL.
* Один маршрутизатор MikroTik RouterOS v7: правила блокировки и аудит безопасности только для чтения (S-00..S-35).
* WinForms Configurator (22 вкладки) и уведомитель в области уведомлений.
* Локальная база SQLite/WAL с шардированием, хранением и резервным копированием/восстановлением.

Не входит в издание (есть в Pro)
--------------------------------
* Пробный прогон ответа (`Firewall.ResponseDryRun`).
* HTTPS REST API только для чтения (`Api.Enabled`).
* Экспорт в SIEM (CEF / LEEF 2.0 / NDJSON).
* Канал push в Zabbix и его команды подготовки.
* Корреляция между хостами.

Если что-то из этого настроено здесь, служба запускается как обычно, пишет по одному явному
предупреждению на каждую возможность с указанием издания, где она работает, и ничего для неё не
делает. Она никогда не отказывается запускаться: потерять локальную детекцию из-за несовпадения
лицензии было бы хуже самого несовпадения.

Сборка и проверка
-----------------
    dotnet build RdpAudit.sln -c Release -p:Platform=x64
    dotnet test  RdpAudit.sln -c Release --no-build -p:Platform=x64

Заголовок окна заканчивается на «- Community», а `GetEditionInfo` (IPC 102) сообщает, какие
возможности содержит этот двоичный файл.
